01 / About

I ship things
that work

Full-stack developer, 3rd year B.Tech at Cummins College, Pune. I build fast and ship — Stashly hit 20+ users in its first week on the Chrome Web Store.

Stashly is a Chrome extension that saves any link with one click and lets you search it back intelligently. Under the hood it runs a hybrid search engine — pgvector cosine similarity for semantic matching plus PostgreSQL full-text ranking with query expansion and dynamic score cliff detection. The backend is deployed on Render via GitHub CI/CD; I added date-range filtering and a save-current-tab feature within days of launch based on real user feedback.

I care about the full loop: from data model to deployed product. Outside code, I compete in basketball, placed 3rd at Central India Hackathon, and volunteered a year at an NGO rehoming 200+ animals.
